Hola mamá, hola papá

CUNABIT está pensado para vigilar al bebé usando dos dispositivos en la misma red privada, sin instalar nada y sin crear una cuenta.

Red privada primero

Funciona cuando ambos móviles están en la misma WiFi o cuando uno comparte datos y el otro se conecta a ese hotspot. El vídeo y el audio viajan directos entre los dispositivos.

Emparejamiento temporal

Al principio se usa un buzón temporal en Vercel para que los dos dispositivos se encuentren. Ese intercambio va cifrado con tu PIN y caduca a los 5 minutos.

Sin cuentas

No hay registro, contraseña guardada ni lista de usuarios. Si terminas la sesión, el código se borra y para volver a conectar hay que emparejar otra vez.

¿Cómo funciona CUNABIT?

CUNABIT usa WebRTC para conectar dos dispositivos directamente cuando están en la misma WiFi o hotspot compartido.

¿Va por internet?

El vídeo y el audio no pasan por servidores. Solo el emparejamiento usa un buzón temporal cifrado para intercambiar los datos necesarios de conexión.

PIN y código

El PIN de 6 dígitos protege el emparejamiento. El código identifica el buzón temporal. Ambos son necesarios y el código caduca.

Avisos

El monitor muestra un aviso, vibra si el dispositivo lo permite y emite un pitido corto cuando detecta sonido alto durante unos segundos.

La sensibilidad decide cuánto sonido hace falta para avisar: alta avisa antes, baja avisa solo con sonidos más fuertes.

Consejos

  • Conecta el móvil-cámara a un cargador.
  • Evita bloquear la pantalla del móvil-cámara.
  • Si cambias de WiFi o hotspot, empareja de nuevo.
  • Usa el botón de encuadre si prefieres ver toda la imagen.
